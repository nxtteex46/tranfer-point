## รัน

```bash
npm install
npm run dev
```

เปิด http://localhost:5173

## Flow

เดินด้วยการกดในหน้าจอเท่านั้น ไม่มีเมนู debug

```
รายการพาร์ตเนอร์ (บัตรสมาชิก / โอนคะแนนให้เพื่อน)
├── แตะพาร์ตเนอร์รายใดก็ได้ ─→ เลือกจำนวน ─→ ตรวจสอบข้อมูล ─→ M PIN ─→ สลิปการโอน ─→ กลับหน้าหลัก
└── แตะแท็บ "โอนคะแนนให้เพื่อน" ─→ เลือกจำนวน ─→ ตรวจสอบข้อมูล ─→ M PIN ─→ สลิปการโอน ─→ กลับหน้าหลัก
```

หน้าเลือกจำนวน หน้าตรวจสอบ และหน้าสลิป ใช้คอมโพเนนต์ชุดเดียวกันทุกพาร์ตเนอร์
พาร์ตเนอร์ที่เลือกจะถูกส่งต่อเป็น params ไปจนถึงสลิป — ชื่อ โลโก้ หน่วย อัตราแลก
และยอดที่กรอกจะเปลี่ยนตามทั้งสาย

ปุ่มย้อนกลับบนหัวจอ และปุ่ม `Esc` ใช้ถอยกลับได้

## สิ่งที่กดได้จริง

- แท็บ โอนคะแนน จากบัตร / โอนคะแนนให้เพื่อน
- แถวพาร์ตเนอร์ทั้ง 5 ราย — เข้าหน้าเลือกจำนวนของพาร์ตเนอร์นั้น
- ช่องกรอกจำนวน (`components/AmountField.jsx`) — ทำครบ 4 สถานะตาม Figma node `5225:1217`
  | สถานะ | เส้นใต้ | ปุ่ม −/+ | อื่นๆ |
  | --- | --- | --- | --- |
  | Default (ยังไม่กรอก) | 1px `#E6E6E6` | ซ่อน | placeholder `0` เทาอ่อน |
  | Focus (กำลังพิมพ์) | 2px `#111111` | แสดง | label เข้มขึ้น + caret |
  | Filled (พิมพ์เสร็จ) | 1px `#E6E6E6` | ซ่อน | ตัวเลขดำ |
  | Error (คะแนนไม่พอ) | 2px `#D32F2F` | แสดง (ปุ่ม + ปิด) | helper แดง |

  ปุ่ม "ถัดไป / ยืนยัน" จะ **disable** จนกว่าจะกรอกจำนวน และช่อง "บันทึก" เป็น placeholder
  ถ้าเว้นว่าง สลิปจะใช้ข้อความตั้งต้น "โอนไป …" ให้เอง

  ยอดขั้นต่ำ **ไม่ใช่ error** — เข้าหน้ามาช่องว่างเป็น placeholder, helper สีเทาบอกขั้นต่ำ
  ตลอดเวลา และถ้ากรอกไม่ถึงขั้นต่ำจะปัดขึ้นให้อัตโนมัติตอนออกจากช่อง
  (ปัดตอนกำลังพิมพ์ไม่ได้ เพราะจะพิมพ์เลขหลายหลักไม่ได้) helper จะเปลี่ยนเป็น
  "ปรับเป็นยอดขั้นต่ำ … ให้แล้ว" ขั้นต่ำอ่านจากบรรทัดขาออกในหน้ารายการ
  เช่น PointX = `110 M Point = 100 Point X` → ขั้นต่ำ 110
- ชิปจำนวนด่วน — ยอดที่ได้รับคำนวณสดตามอัตราของพาร์ตเนอร์ที่เลือก
- ช่องบันทึก พร้อมตัวนับ 0/40
- "ดูทั้งหมด" ขยายเงื่อนไข
- เลือกลายพื้นหลังสลิป 6 ลาย — เปลี่ยนพื้นหลังของสลิปทันที

## Assets

รูปและไอคอนทั้งหมด export จาก Figma แล้วเก็บไว้ใน `public/assets/`
(URL ของ Figma หมดอายุใน 7 วัน จึงต้องดาวน์โหลดมาเก็บ)

ข้อยกเว้นเดียว: เส้นคั่น 1px สองเส้นในหน้าเลือกจำนวน (Hero Rule, Rule)
ใช้ CSS border แทน SVG ที่ export มา เพราะเป็นเส้นตรงล้วน

## ข้อมูลที่ยังเป็นของสมมติ

ตามที่ตกลงไว้ตอนออกแบบใน Figma — ต้องเปลี่ยนก่อนใช้งานจริง

- อัตราแลกดึงจากบรรทัดขาออกในหน้ารายการของ Figma ตรงตัว
  - Blueplus+ บรรทัดขาออกในไฟล์เขียนว่า "400 M Point = 160 Air Asia Point" ซึ่งน่าจะพิมพ์ผิด
  - MAAI ไฟล์ระบุแต่อัตราขาเข้า หน้าจอจึงไม่แสดงยอดแปลง
- **PointX โอนได้เฉพาะ 8 อัตราที่กำหนด** (110/220/550/990/1,100/2,200/3,300/5,500 M Point)
  ปุ่ม −/+ เดินทีละขั้น พิมพ์เองแล้วปัดเข้าขั้นใกล้สุดตอนออกจากช่อง ชิปด้านล่างคือทั้ง 8 ขั้น
  พาร์ตเนอร์อื่นยังคิดเป็นอัตราส่วนเพราะไฟล์ให้มาแค่บรรทัดเดียว
- หน้า M PIN ไม่ตรวจรหัสจริง กดครบ 6 หลักแล้วไปหน้าสลิปเลย
- เลขบัญชีปลายทางมีจริงเฉพาะ Point X พาร์ตเนอร์อื่นแสดงเป็น "-"
- เงื่อนไขในหน้าเลือกจำนวนเป็นข้อความ ROP ตามที่อยู่ในไฟล์ Figma ใช้ร่วมกันทุกพาร์ตเนอร์
- ชื่อเจ้าของบัญชี "PANISA PUNJAVORN" มีจริงเฉพาะเคส Dtac
- วันที่ทำรายการและหมายเลขอ้างอิงเป็นค่าคงที่
